# AGENTS.md — Projekt-Einstieg für Agenten

Dieses Repo nutzt die portablen Arbeitsregeln unter
[`instructions/AGENTS.md`](instructions/AGENTS.md) als Single-Source-of-Truth.
Lies diese Datei vor jeder Arbeit an diesem Repo.

Zusätzlich für dieses Repo:
- Bei Doku-/Instruction-Änderungen gilt das Doc-Harness:
  [`doc-harness/README.md`](doc-harness/README.md).
- Bei Code-/Skript-Änderungen gilt das Dev-Harness:
  [`harness/README.md`](harness/README.md).
- Vor einer Fertig-Meldung mindestens `make verify-docs` ausführen und das
  beobachtete Ergebnis nennen.
- Keine Commits ohne explizite Freigabe.
